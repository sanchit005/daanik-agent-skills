# Security Policy

## Scope
This repository contains instruction-based AI Skills and documentation. It does not intentionally include executable code in the Skills. Future scripts or integrations will be reviewed separately.

## Please do not
- Publish passwords, API keys, access tokens, OTPs, PINs, recovery codes or private user data in issues or pull requests.
- Upload unredacted financial statements, identity documents, client records or private correspondence.
- Run scripts from untrusted forks without reviewing them.

## Reporting a vulnerability
Please use GitHub's private vulnerability reporting or Security Advisories feature for this repository where available: https://github.com/sanchit005/daanik-agent-skills/security/advisories/new

Do not disclose a suspected vulnerability publicly before maintainers have had a reasonable opportunity to assess and address it. Include the affected path, impact, reproduction steps and any suggested mitigation, without including real secrets or another person's data.

## Response
Maintainers will assess reports, coordinate a fix and publish an appropriate advisory when needed. No response-time guarantee is made in this policy.

## Safety-sensitive content
For a suspected financial scam or active account compromise, do not open a GitHub issue containing account details. Contact your bank/payment provider using its official channel and follow local official reporting guidance.

# Changelog

All notable changes to Daanik Everyday AI Skills are documented here.

## [0.1.0] — 2026-11-15 — Public preview

- Added eight everyday-use Agent Skills.
- Added detailed user guidance, starter prompts, workflows, examples, expected response formats and safety boundaries.
- Added behavioural design principles and an ethical persuasion policy.
- Added OpenAI interface metadata in `agents/openai.yaml`.
- Added platform-native layouts for Codex, Claude Code and GitHub Copilot.
- Added per-Skill SWOT, PESTLE and Porter's Five Forces analysis.
- Added 32 evaluation scenarios and a human scoring rubric.
- Added installation, contribution, security, trademark and release documentation.
- Added Skill packaging and structural validation scripts.
- Added Daanik Eduventures Private Limited copyright and MIT License notices.

This is an initial public preview. Behavioural quality and platform compatibility should continue to be tested across supported host versions.
